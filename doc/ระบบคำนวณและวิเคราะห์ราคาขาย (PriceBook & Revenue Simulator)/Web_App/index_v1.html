Ratio (0.5)
สรุปสูตรคำนวณที่ใช้ในระบบ:
  • RawPrice = BasePrice × Multiplier
  • NetWeb = FinalPrice / (1 + Tax) − (FinalPrice × WebFee% + WebFixedFee) − VariableCost
  • NetStore = FinalPrice / (1 + Tax) × (1 − StoreFee%) − VariableCost
  • Target = BasePrice × TargetRatio
  • Pass = ผ่าน เมื่อ MIN(NetWeb, NetStore) ≥ Target
  • MinWeb = (Target + WebFixedFee + VariableCost) / (1/(1+Tax) − WebFee%)
  • MinStore = (Target + VariableCost) / ((1 − StoreFee%)/(1+Tax))
  • MinRaw = MAX(MinWeb, MinStore)
  • MinPrice = ปัดขึ้นเป็นราคาจิตวิทยาลงท้ายด้วย .49 หรือ .99
  • Recommended = MAX(FinalPrice, MinPrice)
