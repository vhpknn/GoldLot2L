ทำระบบถ้าเป็น app android หรือ ios แล้ว
ให้เป็น offline แต่เชื่อมต่อเพื่อตรวจ อัพเดท และตรวจ การ subscription
โดยให้ข้อมูลทุกอย่างอยู่ในเครื่องของ user ถ้า subscription หมดอายุก็จะกลับไปโหมด ปกติ อัตโนมัติ แม้จะอยู่สถานะ offline เพราะอ้างอิงตามวันที่
user ไม่จะเป็นต้อง login ใช้งาน ระบบจะบันทึกหลังบ้านเป็นไฟล์ json ทุกครั้งที่กดทำภาระกิจ โดยจะบันทึกเป็น ชื่อสินทรัพย์ วันที่ เวลา โดยระบบจะดึง บันทึกล่าสุดเสมอ และไฟล์ที่บันทึกจะถูกเก็บ ย้อนหลังไม่เกิน 30 ไฟล์ ไฟล์เก่าจะถูกลบทิ้งอัตโนมัติ ไม่ให้รกและกินพิ้นที่ของมือถือมากไป
แต่ถ้า user login ก็สามารถ connect ผ่าน clound ได้ เช่น goolge drive หรือแชร์ไป app ต่างๆ  ได้ตามที่ user สะดวก หรือส่ง email ได้ เพราะไฟล์ไม่ได้ใหญ่  เพื่อ backup ข้อมูล ไฟล์ json ได้กรณี กู้ข้อมูลตอนเครื่องมือถือ มีปัญหา

ไฟล์ สำรองข้อมูล ทั้งหมด อยู่ใน app โดย app จะกันพื้นที่ vault ให้มากกว่าไฟล์ที่เก็บ ประมาณ 3 mb เสมอ สำหรับเก็บข้อมูล ไฟล์ json ข้อมูลที่เก็บไม่สามาถลบได้ เพราะมันจะถูกลบเองอัตโนมัติเมื่อข้อมูลใหม่มาเกิน 30 ไฟล์ เพื่อป้องกันการเผลอลบ 

user สามารถกำหนด pin เพื่อเข้าใช้งาน app ได้ ป้องกันข้อมูลส่วนตัว
