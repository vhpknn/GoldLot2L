# GoldLot2L Market Readiness Blueprint v0.2
## แผนความพร้อมของตลาด + แผนโปรโมตแบบปลอดภัยต่อกฎหมาย (แยกจาก Web App Blueprint)

วันที่: 11 พ.ย. 2026 | สถานะ: ร่างหลังการค้นหา ยังไม่ผ่านการตรวจโดยทนายหรือที่ปรึกษาท้องถิ่น

> **อ่านก่อน**
> 1. เอกสารนี้ไม่ใช่คำปรึกษากฎหมาย ภาษี หรือการเงิน
> 2. ข้อมูลกฎหมายส่วนใหญ่มาจากบทความของบริษัทที่ปรึกษาและบล็อก ยกเว้นเรื่อง OFAC, FCA (สหราชอาณาจักร) และหน้านโยบายโฆษณาของ Google/Meta ซึ่งมาจากเว็บของหน่วยงานหรือแพลตฟอร์มโดยตรง กฎและนโยบายเปลี่ยนเร็ว บางจุดแหล่งข้อมูลขัดกัน
> 3. คะแนนความยากและอันดับเป็นดุลยพินิจของผู้ร่าง ไม่ใช่ข้อเท็จจริง
> 4. "พร้อมทำได้เลย" = พร้อมที่สุดตามข้อมูลที่ตรวจแล้ว ไม่ได้แปลว่าข้ามการตรวจกฎหมาย ทุกประเทศต้องผ่านประตูตรวจ (ข้อ 8) ก่อนเปิด
> 5. สิ่งที่ยังไม่ได้ตรวจ ระบุว่า "ยังไม่ได้ตรวจ" ไม่ได้เดา
> 6. **ไม่มีสื่อโปรโมตใดในเอกสารนี้ที่รับรองว่า "ถูกกฎหมายทุกประเทศ"** ต้องให้ทนายท้องถิ่นอนุมัติก่อนใช้งานจริงเป็นรายประเทศ

## 1. สรุปผู้บริหาร

| กลุ่ม | ประเทศ | ความหมาย |
|---|---|---|
| **A: พร้อมก่อน** | ไทย (ตลาดตั้งต้น), สิงคโปร์, มาเลเซีย, ญี่ปุ่น, สหราชอาณาจักร | อุปสรรคตามข้อมูลที่พบต่ำ ไม่พบข้อบังคับเก็บข้อมูลในประเทศแบบเข้ม แต่ยังต้องผ่านประตูตรวจ |
| **B: ต้องทำขั้นตอนก่อนเปิด** | สหภาพยุโรป, อินโดนีเซีย, ตุรกี, อินเดีย, UAE, เวียดนาม, ซาอุดีอาระเบีย | ต้องจดทะเบียน มีตัวแทน/ระบบจ่ายเงินท้องถิ่น หรือยืนยันเรื่องเก็บข้อมูลในประเทศก่อน |
| **C: โปรเจกต์ใหญ่แยก** | จีน (แผ่นดินใหญ่), รัสเซีย | ต้องมีนิติบุคคล/เซิร์ฟเวอร์ในประเทศ หรือติดมาตรการคว่ำบาตร |
| **D: ไม่เปิด** | ประเทศที่ถูกคว่ำบาตรทั้งประเทศ | บล็อกการสมัครและการจ่ายเงิน |

ลำดับคลื่น: 0 ไทย -> 1 สิงคโปร์/มาเลเซีย -> 2 ญี่ปุ่น/สหราชอาณาจักร -> 3 อินโดนีเซีย/EU ทีละประเทศ -> 4 ตุรกี/อินเดีย -> 5 เวียดนาม/UAE/ซาอุฯ -> 6 จีน/รัสเซีย (ถ้าจะทำ)

หลักโปรโมต (ย่อ): โปรโมตแอปเป็น "สมุดบันทึกและเครื่องมือเรียนรู้" ไม่โปรโมต "สินทรัพย์" หรือ "ผลตอบแทน" ใช้ตัวอย่างสมมติที่ผ่านการตรวจรายประเทศ (รายละเอียดข้อ 9)

## 2. เงื่อนไขพื้นฐานก่อนเปิดประเทศใด
- ระบบ i18n (ไฟล์ภาษา, Intl, RTL ถ้าจำเป็น)
- `asset_config` ตั้งหน่วย สกุลเงิน ทศนิยมต่อสินทรัพย์
- `country_rules` (อายุขั้นต่ำ ผู้ปกครอง ภาษา สกุลเงิน สถานะการเปิดประเทศ ตัวแทนท้องถิ่น ข้อกำหนดเก็บข้อมูล **สถานะโปรโมต**)
- disclaimer ล็อก แปลโดยผู้เชี่ยวชาญ ; นโยบายความเป็นส่วนตัวแยกภูมิภาค
- ระบบบล็อกการสมัคร/จ่ายเงินตามประเทศ
- local-first ช่วยลดข้อมูลบนเซิร์ฟเวอร์ แต่บัญชีผู้ใช้ อีเมล สถานะสมาชิก ยังเป็นข้อมูลส่วนบุคคล

## 3. วิธีให้คะแนนความยาก
คะแนน 1 = ง่ายสุด, 5 = ยากสุด ค่าเฉลี่ยถ่วงน้ำหนัก

| ปัจจัย | น้ำหนัก | ความหมาย |
|---|---|---|
| กฎหมาย/ข้อมูลส่วนบุคคล | 40% | เก็บข้อมูลในประเทศ จดทะเบียน ตัวแทน ส่งข้อมูลข้ามพรมแดน |

## 4. รายละเอียดแต่ละกลุ่ม

### 4.1 กลุ่ม A
**ไทย (ตลาดตั้งต้น)**: ภาษาไทย / บาททอง / THB ; มีตัวอย่างแอปออมทองในประเทศ (เป๋าตัง Gold Wallet ขั้นต่ำ 0.05 บาททอง แหล่งข้อมูลเป็นโพสต์ผู้ใช้) ; Stripe เริ่มให้บริการธุรกิจไทยตามบทความที่พบ ; PDPA ผู้เยาว์ต่ำกว่า 20 ปี ต่ำกว่า 10 ปีต้องผู้ปกครองยินยอม ; งานที่ต้องทำ: ผู้เชี่ยวชาญตลาดทุน/ก.ล.ต. ตรวจถ้อยคำและการเก็บเงิน ; ยังไม่ได้ตรวจ: ภาษีบริการดิจิทัล, การจดทะเบียนธุรกิจ, กฎโฆษณาการเงินของไทย
**สิงคโปร์** (ยังไม่ได้ตรวจ localization): อังกฤษ / กรัม / SGD ; บัญชีโลหะมีค่าผ่านแอปธนาคาร (OCBC, UOB, DBS) ; ยังไม่ได้ตรวจ PDPA สิงคโปร์และกฎเครื่องมือการเงิน
**มาเลเซีย** (ยังไม่ได้ตรวจ localization): มาเลย์/อังกฤษ/จีน / กรัม / MYR ; Maybank MAE บัญชีทองรวมแบบชะรีอะห์ ; ยังไม่ได้ตรวจ PDPA มาเลเซีย
**ญี่ปุ่น** (ยังไม่ได้ตรวจ localization): ญี่ปุ่น / กรัม / JPY ; วัฒนธรรมออมทองรายเดือน เริ่มที่ 3,000 เยน ; คำแปลต้องให้เจ้าของภาษาตรวจ ; ยังไม่ได้ตรวจ APPI
**สหราชอาณาจักร**: อังกฤษ / กรัม-ออนซ์ / GBP ; Royal Mint DigiGold, BullionVault ; ต้องมีนโยบายความเป็นส่วนตัวแบบ UK GDPR ; **การโปรโมตเป็นประเด็นเข้มของ FCA (ข้อ 9)**

### 4.2 กลุ่ม B
| ประเทศ | ขั้นตอนก่อนเปิด | หลักฐานที่พบ | ยังไม่ได้ตรวจ |
|---|---|---|---|
| สหภาพยุโรป | นโยบาย GDPR, สิทธิ์ลบ/ส่งออก, ตัวแทนในสหภาพ (ถ้าเข้าเกณฑ์), เปิดทีละประเทศ | GDPR ไม่บังคับเก็บข้อมูลในภูมิภาคเสมอ แต่ควบคุมการส่งออก | กฎผู้บริโภค, VAT บริการดิจิทัล |
| อินโดนีเซีย | จดทะเบียน PSE กับ Komdigi, ผู้ติดต่อท้องถิ่น | ไม่จดอาจถูกบล็อก ; เอกชนเก็บข้อมูลนอกประเทศได้ภายใต้เงื่อนไข | e-wallet/โอนธนาคาร, กฎโฆษณาการลงทุน |
| ตุรกี | KVKK มาตรา 9 ส่งข้อมูลออก (ปรับปรุงมีผล 1 มิ.ย. 2024) | ธนาคารมีบัญชีทองผ่านแอป | การจ่ายเงินท้องถิ่น, กฎผู้บริโภค |
| อินเดีย | ผู้ให้บริการชำระเงินท้องถิ่น (UPI), ข้อมูลการชำระเงินต้องเก็บในประเทศ, DPDP | ตลาดทองดิจิทัลใหญ่ที่สุดที่พบ | หลายภาษา, GST, กฎสโตร์ |
| UAE | ยังไม่ได้ตรวจ | - | ทั้งหมด |
| เวียดนาม | **ต้องยืนยันกับทนายท้องถิ่น** แหล่งข้อมูลขัดกัน | แหล่งหนึ่งว่ากฎใหม่ (ผล 1 ก.ค. 2026) ต้องเก็บข้อมูลในประเทศ อีกแหล่งว่าเข้าข่ายเมื่อมีเงื่อนไขและคำสั่ง | e-wallet, กฎโฆษณา |
| ซาอุฯ | ข้อมูลส่วนบุคคล/อ่อนไหวควรอยู่ในประเทศเว้นแต่ได้ยกเว้น | PDPL บังคับใช้ ก.ย. 2024 | กฎการเงิน, ภาษาอาหรับ (RTL) |

### 4.3 กลุ่ม C
**จีน**: ทางเลือก A เซิร์ฟเวอร์นอกจีน (ไม่ต้อง ICP แต่ช้า/ไม่เสถียร/เข้า Play ไม่ได้) ; B เซิร์ฟเวอร์ในจีน (ต้อง ICP + นิติบุคคลในจีน ใบอนุญาตพาณิชย์ถ้าเก็บเงิน ต่างชาติถือหุ้นจำกัด) ; C WeChat Mini Program/สโตร์จีน (ต้องเขียนใหม่ มีนิติบุคคลหรือพันธมิตร จดแจ้งแอป) ; PIPL ใช้กับบริการที่ประมวลผลข้อมูลคนในจีนแม้ให้บริการจากต่างประเทศ โทษสูงสุด 50 ล้านหยวน ; ต้องเปลี่ยน: การจ่ายเงิน, ที่เก็บสำรอง, การแจ้งเตือน, แหล่งราคา, ถ้อยคำ ; ยังไม่ได้ตรวจ: การเข้าถึง Stripe/Cloudflare/Drive จากในจีน ฯลฯ ; ข้อเสนอ: ทดลอง A วัดความต้องการ แล้วค่อยพิจารณา B/C กับพันธมิตร
**รัสเซีย**: 152-FZ ต้องเก็บข้อมูลพลเมืองรัสเซียในฐานข้อมูลในประเทศ และแจ้งก่อนส่งข้อมูลข้ามพรมแดน (ตั้งแต่ มี.ค. 2023) ; มีมาตรการคว่ำบาตรสหรัฐฯ เฉพาะภาคส่วน ; ไม่เปิดในระยะแรก

### 4.4 กลุ่ม D
ประเทศที่ถูกคว่ำบาตรทั้งประเทศตาม OFAC (เช่น คิวบา อิหร่าน เกาหลีเหนือ ซีเรีย) และบางภูมิภาค (เช่น ไครเมีย โดเนตสก์ ลูฮันสก์) ; บล็อกการสมัครและการจ่ายเงิน ; ตรวจรายชื่อ SDN ตามคำแนะนำทนาย ; รายการเปลี่ยนตามเวลา ต้องตรวจจากเว็บ OFAC และหน่วยงานของประเทศอื่น

## 5. ความน่าสนใจของตลาด (แยกจากความยาก)
ไม่ใช่อันดับผู้ใช้ เพราะไม่พบตัวเลขผู้ใช้ทองรายประเทศที่เทียบกันได้

| ประเทศ | หลักฐานที่พบ | ความเชื่อถือ |
|---|---|---|
| อินเดีย | ผู้ใช้ทองดิจิทัลราว 50-55 ล้านคน ; ธุรกรรมทองผ่าน UPI ราว 50.9 ล้านรายการ (ม.ค. 2025) -> 99.8 ล้าน (ส.ค. 2025) | ต่ำ-กลาง (บล็อก/สื่อ) |
| จีน | ฟีเจอร์ออมทองใน Alipay/Yu'e Bao ตัวเลขเป็นของแพลตฟอร์มรวม | ต่ำ |
| อินโดนีเซีย | Tring! ของ Pegadaian ราว 5 ล้านผู้ใช้ ; ธนาคารใหญ่ขายทอง Pegadaian ในแอป | กลาง |
| ตุรกี/ญี่ปุ่น/สิงคโปร์/มาเลเซีย/UK/ยุโรป/เวียดนาม | มีบริการทองดิจิทัล/บัญชีทอง ไม่พบตัวเลขผู้ใช้ | ไม่มีตัวเลข |

## 8. ประตูตรวจก่อนเปิดทุกประเทศ (Market Launch Gate)
ต้องผ่านครบก่อนเปลี่ยนสถานะเป็น "เปิด"
1. [ ] ทนาย/ที่ปรึกษาท้องถิ่นตรวจ: ถ้อยคำการลงทุน, สมุดบันทึก vs คำแนะนำ, การเก็บเงิน
2. [ ] กฎข้อมูลส่วนบุคคล: เก็บในประเทศ? จดทะเบียน? ตัวแทน? โอนข้อมูลข้ามพรมแดน?
3. [ ] ผู้เยาว์: เกณฑ์อายุ ความยินยอมผู้ปกครอง
4. [ ] นโยบายความเป็นส่วนตัวและข้อกำหนดใช้งาน แปลโดยผู้เชี่ยวชาญ
5. [ ] ระบบจ่ายเงินที่ถูกกฎหมาย + ภาษีบริการดิจิทัล
6. [ ] ภาษา: เจ้าของภาษาตรวจข้อความเกี่ยวกับเงิน ทดสอบตัวเลข/วันที่/สกุลเงิน (RTL ถ้าจำเป็น)
7. [ ] หน่วยทองและสกุลเงิน: ตั้ง asset_config ถูกต้อง ทดสอบการคำนวณ
8. [ ] แหล่งราคา/ATH: ผู้ใช้กรอกเองได้ ค่าแนะนำใช้แหล่งที่เผยแพร่ซ้ำได้
9. [ ] การเข้าถึง: ทดสอบจากเครือข่ายในประเทศนั้นจริง
10. [ ] การสนับสนุนผู้ใช้: ช่องทางและภาษา
11. [ ] บล็อก/ปลดบล็อกตาม country_rules ทดสอบแล้ว
12. [ ] ย้อนกลับ: ปิดประเทศได้เร็วโดยไม่กระทบประเทศอื่น
13. [ ] **สื่อโปรโมตชุดแรกของประเทศนั้นผ่านการอนุมัติตามขั้นตอนข้อ 9.6 แล้ว** (ทะเบียนข้อความ + ผู้อนุมัติ)
14. [ ] **ตรวจนโยบายโฆษณา (Google/Meta/ช่องทางอื่น) ของประเทศนั้นแล้ว** และตัดสินใจว่าจะลงโฆษณาหรือไม่

## 9. แผนโปรโมตแบบปลอดภัยต่อกฎหมาย (ใหม่ใน v0.2)

### 9.1 เป้าหมายและหลักการ
เป้าหมาย: ทำให้ผู้คนในแต่ละประเทศ "รู้จักและเข้าใจ" แอปในฐานะสมุดบันทึก ผ่านตัวอย่างที่คุ้นเคย โดยลดความเสี่ยงถูกตีความว่า *ชักชวนให้ซื้อ/ลงทุนสินทรัพย์* หรือ *ให้คำแนะนำ*
หลักการ 8 ข้อ
1. **โปรโมตเครื่องมือ ไม่โปรโมตสินทรัพย์**: ข้อความหลัก = "จดบันทึกการออมให้เป็นระเบียบ" ไม่ใช่ "ซื้อ/ออมสินทรัพย์ X"
2. **ตัวอย่างเป็นสมมติเสมอ**: เป็นสถานการณ์ตัวอย่าง ตัวเลขสมมติ ติดป้ายชัดเจน ไม่ใช้ราคาจริงล่าสุดหรือผลตอบแทนย้อนหลังเป็นจุดขาย
3. **ไม่มีผลตอบแทน ไม่มีคำรับประกัน ไม่มีการเปรียบเทียบเชิงแนะนำ** (เช่น "ทองดีกว่าฝากธนาคาร")
4. **ไม่มีปุ่มพาไปซื้อ**: สื่อโปรโมตและตัวอย่างในแอปไม่ลิงก์ไปผลิตภัณฑ์การเงิน/โบรกเกอร์/แอปซื้อขาย (ไม่ทำ affiliate)
5. **ข้อความเดียวกันในทุกช่องทาง**: ใช้เฉพาะข้อความที่อยู่ใน "ทะเบียนข้อความที่อนุมัติ" (claims register) ห้ามด้นสดบนโซเชียล
6. **เปิดประเทศก่อน โปรโมตทีหลัง**: โปรโมตเฉพาะประเทศที่สถานะ "เปิด" และผ่านประตูตรวจข้อ 13-14
7. **เด็กและผู้เยาว์**: ไม่ทำการตลาดมุ่งเป้าเด็กโดยตรง สื่อสำหรับเด็กต้องมุ่งผู้ปกครองและเน้นการเรียนรู้การออม
8. **เก็บหลักฐาน**: บันทึกว่าใครอนุมัติข้อความอะไร เมื่อไร ใช้ที่ไหน เพื่อตรวจสอบย้อนหลังและถอดได้เร็ว

### 9.2 จุดยืนข้อความ (Positioning)
| ใช้ได้ (ร่าง ต้องให้ผู้ตรวจท้องถิ่นอนุมัติ) | ไม่ควรใช้ |
|---|---|
| "สมุดจดการออมของคุณ ตั้งกฎเอง ดูสรุปเอง" | "เริ่มออมทองวันนี้ รวยแน่" |
| "บันทึกการซื้อ-ขายและดูสถิติของคุณในที่เดียว" | "ซื้อตอนราคาตก ขายตอนถึงเป้า ทำกำไรแน่นอน" |
| "ตัวอย่างสมมติเพื่อการเรียนรู้" | "ผู้ใช้ทำกำไรได้ X% ต่อปี" |
| "แอปนี้ไม่ใช่คำแนะนำการลงทุน และไม่ได้ซื้อขายให้" | "แอปบอกจังหวะซื้อขายให้" |
| "ใช้ได้กับสินทรัพย์ที่คุณเลือกเอง" | "ทองคือสินทรัพย์ที่ดีที่สุด" |
| "ดูได้ทั้งตอนออฟไลน์ ข้อมูลอยู่ในเครื่องคุณ" | "ปลอดภัย 100% ไม่มีความเสี่ยง" |
หมายเหตุ: ข้อความ "ใช้ได้" ข้างต้นเป็นแนวทางของผู้ร่าง ยังไม่ผ่านการอนุมัติจากทนายประเทศใด

### 9.3 ตัวอย่างในแอป (Use-case Templates) ที่ปลอดภัย
หลักออกแบบ
- ทุกเทมเพลตมีป้าย "ตัวอย่างสมมติ ไม่ใช่คำแนะนำ" ติดถาวร และแก้/ซ่อนโดยผู้ใช้ไม่ได้ (ข้อความ locked)
- ผู้ใช้เลือกตัวอย่างจากหลายหมวด ไม่ดันสินทรัพย์เดียว: ทอง / เงินออม / กระปุกเป้าหมาย / สมุดเงินยืม
- ตัวเลขเป็นค่ากลมๆ สมมติ (เช่น 1,000 / 100) และไม่ใช้ราคาตลาดปัจจุบัน
- ไม่มีลิงก์ไปซื้อ ไม่มีชื่อผลิตภัณฑ์หรือแบรนด์ของผู้ให้บริการจริง เว้นแต่ได้รับอนุญาตและทนายตรวจแล้ว
- เป็นข้อมูลในโมดูลตัวอย่าง ผูกกับ country_rules: เปิดชุดตัวอย่างเฉพาะประเทศที่ผ่านประตูตรวจ

| ประเทศ | ตัวอย่างการจดบันทึก (ร่าง) | หมายเหตุ |
|---|---|---|
| ไทย | จดทองสะสมเป็นบาททองแบบสมมติ / กระปุกออมเป้าหมาย | ตรวจโดยผู้เชี่ยวชาญไทยก่อนใช้ |
| อินโดนีเซีย | จดการออมเป็นกรัม / สมุดเงินยืมส่วนตัว | ต้องจด PSE ก่อนเปิด |
| ญี่ปุ่น | จดแผนออมรายเดือนเป็นกรัมและเยน (สมมติ) | เจ้าของภาษาตรวจคำแปล |
| อินเดีย | จดการออมเป็นกรัมและรูปี (สมมติ) | ระวังกฎโฆษณาการเงินของ Google/Meta |
| สหราชอาณาจักร | จดการออมโดยใช้ตัวเลขสมมติ | ทนาย UK ตรวจเรื่อง financial promotion ก่อนใช้ |
| ทุกประเทศ | กระปุกออม / เป้าหมายออม / สมุดเงินยืม | ไม่ผูกกับสินทรัพย์ที่ถูกกำกับ ปลอดภัยที่สุด |

### 9.4 ช่องทางโปรโมตและระดับความเสี่ยง
| ช่องทาง | ความเสี่ยง | แนวทาง | เงื่อนไขก่อนใช้ |
|---|---|---|---|
| เว็บไซต์/บล็อก/SEO (เนื้อหาสอนใช้งาน คำศัพท์ การจดบันทึก) | ต่ำ-กลาง | ใช้ข้อความจากทะเบียนข้อความ ใส่ disclaimer | ผ่านข้อ 13 |
| วิดีโอสอนใช้แอป (สกรีนแคสต์) | ต่ำ-กลาง | ใช้ข้อมูลสมมติ ไม่ใช้เสียง/ข้อความชักชวน | ผ่านข้อ 13 |
| ชุมชนออนไลน์ (กลุ่มออมเงิน/จัดการเงินส่วนบุคคล) | กลาง | ตอบคำถามเรื่องการใช้งาน ไม่ถกเรื่องว่าควรซื้อสินทรัพย์ใด | มีกติกาผู้ดูแลและการตรวจสอบ |
| อีเมล/WhatsApp ถึงผู้ใช้ | กลาง | ต้องมีความยินยอม (opt-in) ใช้ template ที่อนุมัติ ไม่ส่งสัญญาณราคา | ตรวจกฎโปรโมต/ข้อความตรงของประเทศ |
| แอปสโตร์ (คำอธิบาย ภาพหน้าจอ) | กลาง | ใช้ภาพหน้าจอตัวอย่างสมมติ ไม่โชว์ตัวเลขกำไร | ตรวจนโยบายสโตร์ |
| อินฟลูเอนเซอร์/ผู้สอนการเงินส่วนบุคคล | **สูง** | ให้สคริปต์/ข้อความที่อนุมัติเท่านั้น ห้ามพูดถึงผลตอบแทนหรือแนะนำสินทรัพย์ | ทนายท้องถิ่นประเมิน + สัญญาเฉพาะ (ข้อ 9.7) |
| โฆษณาแบบเสียเงิน (Google/Meta/อื่นๆ) | **สูง** | ทดลองเล็กก่อน ตรวจการจัดประเภทของแพลตฟอร์ม | ผ่านข้อ 14 |
| ความร่วมมือกับธนาคาร/ผู้ให้บริการทอง | **สูง** | ทนายตรวจก่อน เรื่องการแนะนำผลิตภัณฑ์ ค่านายหน้า ข้อกำหนดผู้ถือใบอนุญาต | ทนายอนุมัติ |

### 9.5 หมายเหตุรายประเทศ/แพลตฟอร์ม (ที่พบจากหน้าทางการ ณ วันที่ค้น)
**สหราชอาณาจักร (FCA)**
- FCA ระบุว่ากฎ financial promotion ใช้กับทุกช่องทางโฆษณา รวมโซเชียล และต้อง "เป็นธรรม ชัดเจน ไม่ทำให้เข้าใจผิด"
- ผู้ที่ไม่ได้รับอนุญาต เช่น อินฟลูเอนเซอร์ ที่โปรโมตผลิตภัณฑ์ทางการเงินที่อยู่ภายใต้การกำกับโดยไม่ได้รับการอนุมัติจากผู้ได้รับอนุญาต อาจมีความผิดทางอาญา ; FCA เคยสัมภาษณ์ finfluencer 20 รายภายใต้การตักเตือน
- กฎนี้ครอบคลุมอินฟลูเอนเซอร์ที่ไม่ได้รับค่าตอบแทนด้วย (ตามแนวทางที่พบ)
- ผู้ร่างไม่ได้ประเมินว่าแอปสมุดบันทึกเข้าข่าย "ผลิตภัณฑ์ที่อยู่ภายใต้การกำกับ" หรือไม่ -> **ต้องให้ทนาย UK ตัดสิน** ก่อนโปรโมตใน UK
**Google Ads**
- ต้องปฏิบัติตามนโยบาย financial products and services และกฎท้องถิ่นของประเทศที่ลงโฆษณา รวมถึงการแสดงข้อมูลเปิดเผยที่กฎหมายท้องถิ่นกำหนด
- เคยประกาศข้อกำหนดการตรวจสอบนักโฆษณาด้านบริการการเงินในหลายประเทศ เช่น ฝรั่งเศส เยอรมนี อินโดนีเซีย สเปน (ผ่านพันธมิตรตรวจสอบ), บราซิล อินเดีย โปรตุเกส, ออสเตรเลีย สิงคโปร์ ไต้หวัน (เป็นประกาศปี 2022 ปัจจุบันอาจเปลี่ยน ต้องตรวจหน้านโยบายล่าสุด)
**Meta (Facebook/Instagram)**
- ผู้โฆษณาผลิตภัณฑ์การเงินต้องยืนยันตัวตน และอาจต้องแสดงว่าได้รับอนุญาตจากหน่วยงานกำกับของประเทศเป้าหมาย
- นโยบายระบุห้ามโปรโมตผลิตภัณฑ์หรือโอกาสการลงทุนแม้ในรูปเนื้อหาให้ความรู้ เว้นแต่เป็นผู้ที่ได้รับอนุญาตและผ่านการตรวจสอบ
- หน้า Meta ระบุประเทศที่ต้องตรวจสอบ ได้แก่ ไทย สหราชอาณาจักร อินเดีย ออสเตรเลีย ฮ่องกง ไอร์แลนด์ อิสราเอล สเปน ไต้หวัน สหรัฐฯ
- โฆษณาที่ให้ความรู้ทางการเงินทั่วไป โดยไม่โฟกัสผลิตภัณฑ์เฉพาะและไม่เปิดช่องให้ซื้อ/เชื่อมต่อ โดยทั่วไปทำได้โดยไม่ต้องตรวจสอบ -> พื้นที่ที่เราควรอยู่ แต่ผู้ร่างไม่ทราบว่า Meta จะจัดแอปเราเข้าประเภทใด ต้องทดลองส่งจริงและดูผลพิจารณา
**ประเทศอื่นทั้งหมด**: ยังไม่ได้ตรวจกฎโฆษณาและ financial promotion ของไทย ญี่ปุ่น สิงคโปร์ มาเลเซีย ตุรกี เวียดนาม UAE ซาอุฯ EU รายประเทศ อินโดนีเซีย (นอกเหนือจากการจด PSE) จีน รัสเซีย -> ต้องตรวจก่อนวางแผนโปรโมต

### 9.6 กระบวนการอนุมัติสื่อ (Claims Governance)
1. **ทะเบียนข้อความ (Claims Register)**: ตารางเก็บทุกข้อความที่ใช้โปรโมต พร้อมประเทศ ภาษา วันที่ ผู้เสนอ ผู้ตรวจ (ทนาย) สถานะ (ร่าง/อนุมัติ/ถอด) หลักฐานรองรับ
2. **เกณฑ์ต้องห้าม (Red lines)**: ผลตอบแทน การรับประกัน การเปรียบเทียบเชิงแนะนำ การชักชวนให้ซื้อ/ขายสินทรัพย์ การอ้างสถิติผลงานผู้ใช้ การอ้างว่าได้รับการรับรองจากหน่วยงาน
3. **ขั้นตอนอนุมัติ**: ผู้เสนอ -> ตรวจภายใน (ตามเกณฑ์) -> ทนาย/ที่ปรึกษาท้องถิ่น -> อนุมัติ -> เผยแพร่ (ห้ามเผยแพร่ข้อความนอกทะเบียน)
4. **ตรวจภาษา**: เจ้าของภาษาตรวจ ข้อความเกี่ยวกับเงิน/ความเสี่ยงห้ามใช้ตัวแปลอัตโนมัติอย่างเดียว
5. **ตรวจสอบเป็นรอบ**: ทบทวนทะเบียนทุกไตรมาส หรือเมื่อกฎ/นโยบายแพลตฟอร์มเปลี่ยน
6. **ถอดสื่อได้เร็ว**: มีช่องทางและเจ้าของงานชัดเจนสำหรับถอดโฆษณา/โพสต์/วิดีโอภายในเวลาที่กำหนด และบันทึกการถอด
7. **เก็บหลักฐาน**: เก็บสำเนาสื่อทุกชิ้นที่เผยแพร่ วันที่ ช่องทาง และเวอร์ชันข้อความ
8. **ข้อความ locked ในแอป**: disclaimer และป้ายตัวอย่างสมมติ แก้ไม่ได้ ยกเว้นเจ้าของระบบ

### 9.7 แนวทางสัญญากับอินฟลูเอนเซอร์/พันธมิตร (ให้ทนายตรวจก่อนใช้)
- ใช้เฉพาะสคริปต์/ข้อความจากทะเบียนข้อความ ห้ามแก้ความหมาย
- ห้ามพูดถึงผลตอบแทน ราคา หรือแนะนำให้ซื้อ/ขายสินทรัพย์ใดๆ
- ต้องเปิดเผยความสัมพันธ์ทางการค้า (ค่าตอบแทน/สินค้า) ตามกฎของประเทศ
- ต้องแสดง disclaimer ตามที่กำหนด และห้ามตัดต่อให้หายไป
- ส่งงานให้ตรวจก่อนเผยแพร่ ; มีสิทธิ์สั่งถอดทันที
- ห้ามกำหนดเป้าหมายผู้เยาว์ ; ห้ามใช้ภาพ/ข้อความที่ทำให้เข้าใจว่าแอปเป็นผู้ให้คำแนะนำหรือได้รับอนุญาตทางการเงิน
- เก็บหลักฐานการตรวจและการเผยแพร่
- ตรวจว่ากฎท้องถิ่นให้รับผิดชอบการสื่อสารของพันธมิตรที่ทำการตลาดให้เราหรือไม่ (เช่น แนวทางของ FCA เรื่อง affiliate) และมีระบบตรวจสอบรองรับ

### 9.9 วัดผลโดยไม่เสี่ยง
- วัด: จำนวนผู้เข้าชมหน้าสอนใช้, อัตราติดตั้ง/เปิดใช้ครั้งแรก, การใช้ฟังก์ชันบันทึกครั้งแรก, อัตราใช้งานต่อเนื่อง, การอัพเกรดสมาชิก
- ไม่ใช้ตัวชี้วัดเชิงผลตอบแทนผู้ใช้เป็นสื่อโปรโมต
- เก็บข้อมูลวิเคราะห์น้อยที่สุดตามกฎข้อมูลส่วนบุคคลของประเทศนั้น และขอความยินยอมตามกฎ
- ทดลองโฆษณาแบบเล็กและเปรียบเทียบผลการพิจารณา (ผ่าน/ถูกจำกัด/ถูกปฏิเสธ) ก่อนเพิ่มงบ

### 9.10 แผนรับมือเมื่อมีปัญหา
- ถูกปฏิเสธ/จำกัดโฆษณา: หยุดเผยแพร่ข้อความนั้นในทุกช่องทาง ตรวจเหตุผล แก้ในทะเบียนข้อความ ขออนุมัติใหม่
- ได้รับหนังสือเตือน/ข้อร้องเรียนจากหน่วยงานหรือผู้ใช้: ถอดสื่อทันที เก็บหลักฐาน แจ้งทนาย ตรวจสอบสื่ออื่นที่ใช้ข้อความเดียวกัน
- อินฟลูเอนเซอร์พูดนอกสคริปต์: สั่งถอด ใช้สิทธิ์ตามสัญญา แจ้งทนายถ้าเข้าข่ายผิดกฎ
- กฎเปลี่ยน: ปรับสถานะประเทศใน country_rules เป็น "หยุดโปรโมต" ได้ทันที

## 12. สิ่งที่ยังไม่รู้ (ต้องตรวจก่อนอัปเดตเป็น v0.3)
1. กฎข้อมูลส่วนบุคคลและ localization ของ สิงคโปร์ มาเลเซีย ญี่ปุ่น UAE
2. ข้อสรุปเรื่องเวียดนาม (แหล่งข้อมูลขัดกัน)
3. เงื่อนไขผู้ให้บริการจ่ายเงินแต่ละประเทศ (WeChat Pay/Alipay/UPI/e-wallet อาเซียน)
4. การเข้าถึง Google Drive, Cloudflare, Stripe จากแต่ละประเทศ (โดยเฉพาะจีน รัสเซีย)
5. **กฎการโฆษณาและ financial promotion ของแต่ละประเทศ** (ตลาดทุน/ผู้บริโภค) รวมไทย
6. **แพลตฟอร์มโฆษณา (Google/Meta/อื่น) จะจัดประเภทแอปสมุดบันทึกของเราเป็นผลิตภัณฑ์การเงินหรือไม่** ต้องทดสอบส่งจริง
7. **แอปสมุดบันทึกที่มีการคำนวณตามกฎของผู้ใช้เข้าข่ายผลิตภัณฑ์/บริการที่ถูกกำกับ (เช่น ใน UK) หรือไม่** ต้องให้ทนายตัดสิน
8. นโยบายแอปสโตร์ต่อแอปที่ห่อเว็บและการขายสมาชิกในแอป แยกตามประเทศ
9. ภาษีบริการดิจิทัล (VAT/GST) และใบกำกับภาษี
10. ตัวเลขผู้ใช้ที่เทียบกันได้ระหว่างประเทศ

## 13. สรุปสั้น
- **พร้อมก่อน**: ไทย แล้วสิงคโปร์ มาเลเซีย ญี่ปุ่น สหราชอาณาจักร (ต้องผ่านประตูตรวจ)
- **ต้องทำขั้นตอน**: สหภาพยุโรป อินโดนีเซีย ตุรกี อินเดีย UAE เวียดนาม ซาอุฯ
- **โปรเจกต์แยก**: จีน รัสเซีย ; **ไม่เปิด**: ประเทศถูกคว่ำบาตรทั้งประเทศ
- **โปรโมต**: ขายเครื่องมือจดบันทึก ไม่ขายสินทรัพย์ ; ตัวอย่างสมมติ ; ข้อความต้องอยู่ในทะเบียนที่ทนายอนุมัติ ; โฆษณาเสียเงินและอินฟลูเอนเซอร์ทำทีหลังและทีละประเทศ
