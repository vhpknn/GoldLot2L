# GoldLot2L คู่มือใช้งานฉบับชาวบ้าน

แอปช่วยจดและคำนวณการซื้อ-ขายทองคำแท่งแบบ "ทยอยซื้อเมื่อราคาลง ทยอยขายเมื่อได้กำไร"
ไม่ต้องรู้เรื่องโค้ด อ่านตามนี้แล้วใช้ได้เลย

---

## 1. ระบบนี้คืออะไร

GoldLot2L คือ **สมุดจดบันทึก + เครื่องคิดเลขอัจฉริยะ** สำหรับคนที่ซื้อทองแบบแบ่งไม้

- คุณบอกแอปว่า **ราคาทองวันนี้เท่าไร** (ราคารับซื้อและราคาขายออก)
- แอปบอกคุณว่า **วันนี้ควรทำอะไร** เช่น ซื้อกี่ไม้ ไม้ละกี่บาททอง หรือขายไม้ไหนได้แล้ว
- คุณไปซื้อหรือขายจริงในแอปธนาคาร/แอปออมทองของคุณเอง แล้วกลับมา **กดบันทึกในแอปนี้** เพื่อจดไว้

> สิ่งที่แอปนี้ **ไม่ได้ทำ**: ไม่ได้ซื้อขายทองให้คุณ ไม่ได้เชื่อมกับบัญชีธนาคาร ไม่ได้ดึงราคาทองให้
> คุณต้องพิมพ์ราคาเองและกดบันทึกเอง ข้อมูลทั้งหมดอยู่ในเครื่องของคุณ ไม่ถูกส่งไปที่ไหน

---

## 2. ระบบนี้ดียังไง

- **ไม่ต้องคิดเลขเอง** แอปคำนวณจุดซื้อ จำนวนไม้ ขนาดไม้ และราคาที่ควรขายให้ทั้งหมด
- **มีวินัย** ซื้อตามแผนเมื่อราคาลงถึงจุด ขายตามแผนเมื่อได้กำไรถึงเป้า ไม่ต้องใช้อารมณ์ตัดสินใจ
- **แยกเงินเป็น 2 ถัง (Layer 1 และ Layer 2)** เงินคนละก้อน ไม่ปนกัน
- **กำไรทบต้นได้ (Snowball)** กำไรที่ได้จะถูกเอาไปเพิ่มขนาดไม้ถัดไป
- **เห็นภาพรวมชัด** มีสรุปกำไร ประวัติการขาย และรายงาน
- **ใช้ออฟไลน์ได้** ติดตั้งเป็นแอปบนเครื่อง เปิดได้แม้ไม่มีเน็ต (หลังเปิดครั้งแรกแล้ว)
- **ข้อมูลเป็นของคุณ** สำรองเป็นไฟล์เก็บไว้เองได้

---

## 3. ระบบทำงานยังไง (อธิบายด้วยตัวอย่าง)

### คำศัพท์ที่ควรรู้

| คำ | ความหมายแบบง่าย |
|---|---|
| ATH | ราคาทองสูงสุดที่คุณใช้เป็น "จุดอ้างอิง" ของแผน |
| ราคารับซื้อ (Bid) | ราคาที่ร้าน/แอป "รับซื้อ" จากเรา คือราคาตอนที่เราขาย |
| ราคาขายออก (Ask) | ราคาที่ร้าน/แอป "ขายให้" เรา คือราคาตอนที่เราซื้อ (สูงกว่าราคารับซื้อ) |
| ส่วนต่าง | ราคาขายออก ลบ ราคารับซื้อ เป็นต้นทุนที่หนีไม่พ้นทุกครั้งที่ซื้อ |
| ไม้ | ทองที่ซื้อ 1 ครั้ง นับเป็น 1 ไม้ |
| Layer 1 / Layer 2 | เงิน 2 ถัง ถังแรกใช้ซื้อตอนราคาลงไม่มาก ถังสองใช้ซื้อตอนราคาลงลึก |
| Snowball | เอากำไรที่ขายได้ไปเพิ่มเงินซื้อไม้ถัดไป (ลูกบอลหิมะที่ใหญ่ขึ้นเรื่อยๆ) |

### แนวคิดหลัก

1. **ราคาทองลง = ทยอยซื้อ** แอปแบ่งช่วงที่ราคาลงเป็นขั้นๆ ยิ่งลงลึก ยิ่งซื้อเพิ่มทีละไม้
2. **ราคาทองขึ้นถึงเป้ากำไร = ขายไม้นั้น** แต่ละไม้มีเป้าขายของตัวเอง คิดจากราคาที่ซื้อมาจริง บวกกำไรที่ตั้งไว้
3. **ไม้ไหนถึงเป้าก่อน ขายไม้นั้นก่อน** ไม่ต้องรอให้ถึงพร้อมกัน

### ตัวอย่างตัวเลข (ใช้ค่าเริ่มต้นของแอป)

สมมติ ATH = 80,000 บาท ต่อ 1 บาททอง

- **Layer 1** ใช้เงิน 100,000 บาท แบ่ง 15 ไม้ ซื้อทุกครั้งที่ราคาลงอีก 2% จาก ATH และตั้งเป้ากำไร 2%
  จุดซื้อไม้แรกๆ คือ 78,400 / 76,800 / 75,200 ... ไปเรื่อยๆ จนลงรวม 30%
- **Layer 2** ใช้เงิน 100,000 บาท แบ่ง 6 ไม้ เริ่มซื้อเมื่อราคาลงเกิน 30% ไปจนถึง 50% ห่างกันขั้นละประมาณ 3.33% และตั้งเป้ากำไร 3%
  จุดซื้อ L2 คือประมาณ 53,333 / 50,667 / 48,000 / 45,333 / 42,667 / 40,000

ตัวอย่างหนึ่งไม้ของ Layer 1:

- ราคารับซื้อลงมาที่ 75,200 ราคาขายออก 75,400 (ส่วนต่าง 200)
- เงินต่อไม้ประมาณ 6,667 บาท แอปคำนวณได้ 0.08 บาททอง (ปัดลงเป็น 0.01 เสมอ) จ่ายจริงประมาณ 6,032 บาท
- เป้าขายคือ 75,400 + 2% = ประมาณ 76,908 (วัดที่ราคารับซื้อ)
- เมื่อราคารับซื้อถึง 76,908 แอปบอกให้ขาย ได้เงินประมาณ 6,153 บาท กำไรประมาณ 121 บาท

### เรื่องที่ควรรู้

- **ถ้าราคาลงเร็วและลงลึก** แอปจะบอกให้ซื้อหลายไม้พร้อมกันได้ เพื่อให้ครบทุกจุดที่ราคาผ่านมาแล้ว
- **โซนของ Layer 1 ไปจบที่ลง 30% ซึ่งเป็นจุดที่ Layer 2 เริ่มพอดี** สองถังจึงต่อกันสนิท และเงินแต่ละถังไม่ยืมกัน
- **ซื้อแล้วขายเลย ไม่ได้กำไรเสมอไป** เพราะมีส่วนต่างราคา ถ้าขายแล้วซื้อกลับทันทีที่ราคาเดิม จะเสียส่วนต่างฟรี ดูจังหวะเอง แอปเป็นแค่ข้อเสนอ ไม่บังคับ
- **ทองอาจลงต่อได้อีก** ทุนในถังที่ใช้หมดแล้วจะซื้อเพิ่มไม่ได้ จนกว่าจะขายได้หรือเพิ่มทุน

## 4. วิธีใช้งานทุกวัน (ทำตามลำดับ)

### เปิดแอป

เปิดที่อยู่ที่ใช้ประจำ (ตอนนี้คือ `http://localhost:8787/` ต้องเปิดโปรแกรมเซิร์ฟเวอร์ในเครื่องไว้) ใช้ที่อยู่เดิมทุกครั้ง ไม่งั้นข้อมูลจะเป็นคนละชุด

### ขั้นที่ 1 ใส่ราคาวันนี้

- ช่อง **ราคารับซื้อ (Bid)** พิมพ์ราคารับซื้อวันนี้
- ช่อง **ราคาขายออก (Ask)** แอปเติมให้เองเท่ากับราคารับซื้อบวกส่วนต่างที่ตั้งไว้ ถ้าราคาจริงต่าง ให้แก้ช่องนี้ทีหลัง
- ถ้าพิมพ์ผิดหลัก แอปจะเตือนสีแดงใต้ช่อง เช่น ราคาต่ำหรือสูงผิดปกติ หรือสลับ Ask กับ Bid

### ขั้นที่ 2 ดูการ์ด "วันนี้ทำอะไร"

มีได้ 3 แบบ

- **การ์ดสีเขียว "ขาย ... ไม้"** ไม้เหล่านี้ถึงเป้ากำไรแล้ว แสดงเงินที่คาดว่าจะได้และกำไร
- **การ์ดสีฟ้า "ซื้อ: Layer ... จำนวน ... ไม้"** ราคาลงถึงจุดซื้อแล้ว แสดงจำนวนไม้ ขนาดต่อไม้ และเงินที่คาดว่าต้องจ่าย
- **"ไม่ต้องทำอะไร"** ปิดแอปได้เลย

### ขั้นที่ 3 ถ้าจะซื้อ

1. ในการ์ดสีฟ้า ปรับจำนวนไม้ได้ด้วยปุ่ม **−** และ **＋** (ลดได้ถึง 1 ไม้ เพิ่มเกินที่แอปแนะนำไม่ได้)
2. กดปุ่ม **↺ ตามที่แนะนำ** ถ้าอยากกลับไปใช้จำนวนที่แอปแนะนำ
3. ไปซื้อทองจริงในแอปธนาคาร/แอปออมทองของคุณก่อน
4. กลับมากด **ซื้อเสร็จแล้ว บันทึก** จะมีหน้าต่างให้ตรวจ
   - วันที่ซื้อ
   - จำนวนไม้
   - จำนวนบาททองต่อไม้
   - **เงินที่แอปธนาคารหักจริงต่อไม้** ให้แก้ให้ตรงกับยอดจริง เพราะแอปใช้ตัวเลขนี้คำนวณกำไรให้ถูกต้อง
5. กด **บันทึก**

ถ้ายังไม่พร้อมซื้อ **ไม่ต้องกดบันทึก** แอปเป็นแค่คำแนะนำ

### ขั้นที่ 4 ถ้าจะขาย

1. ขายทองจริงในแอปธนาคาร/แอปออมทองของคุณก่อน
2. กลับมากด **ขายเสร็จแล้ว บันทึก** ในการ์ดสีเขียว
3. ช่องของแต่ละไม้คือ **เงินที่เข้าบัญชีจริง** แก้ให้ตรงกับยอดจริง แล้วกดบันทึก

### ขั้นที่ 5 ดูผล

- **สถานะระบบ** บอกว่าราคาลงจาก ATH กี่ % จุดซื้อถัดไปคือเท่าไร และจุดขายถัดไปคือเท่าไร
- **ไม้ที่ถืออยู่** ตารางไม้ที่ยังไม่ขาย พร้อมกำไรขาดทุนตอนนี้
- **สรุปยอด** กำไรที่ขายแล้ว กำไรที่ยังถืออยู่ มูลค่าพอร์ต อัตราชนะ
- **ประวัติการขาย / รายงาน** กดหัวข้อเพื่อขยายดูเมื่อต้องการ (ปกติย่อไว้ให้หน้าจอไม่ยาว)

### เมื่อราคาทำ "จุดสูงสุดใหม่"

ถ้าราคารับซื้อสูงกว่า ATH ที่ตั้งไว้ แอปจะถามว่า **"ราคาทำ ATH ใหม่?"**

- กด **ยืนยัน** แอปจะคำนวณจุดซื้อใหม่ทั้งหมดจาก ATH ใหม่
- กด **ไม่เปลี่ยน** ใช้ ATH เดิมต่อ
- ถ้าราคาสูงกว่าเดิมเกิน 20% แอปเตือนให้ตรวจว่าพิมพ์ถูกหรือไม่ก่อน
- ปรับให้แอปเปลี่ยนเองโดยไม่ถาม หรือไม่เปลี่ยนเลย ได้ในหน้าตั้งค่า

## 5. การตั้งค่า (ส่วน "ตั้งค่า" กดขยายดู)

เปลี่ยนค่าแล้วต้องกด **บันทึกการตั้งค่า** ด้านล่างเสมอ ค่าที่เปลี่ยนมีผลกับการคำนวณจากนี้ไป

### ราคาและโซน

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| ราคาอ้างอิงสูงสุด (ATH) | ราคาจุดอ้างอิงของแผน ใส่ตามที่คุณเลือก | 80,000 |
| ส่วนต่าง Ask−Bid | ส่วนต่างราคาขายออกกับราคารับซื้อ ใช้เติมช่อง Ask ให้อัตโนมัติ ตั้งให้ตรงกับแอปที่คุณใช้ | 200 |
| โซน L2 เริ่มที่ลง (%) | ราคาต้องลงจาก ATH เกินกี่ % ถึงเริ่มซื้อถัง Layer 2 | 30 |
| โซน L2 สิ้นสุดที่ลง (%) | โซนซื้อ Layer 2 ไปสิ้นสุดที่ลงกี่ % | 50 |

### ทุนและไม้

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| ทุนหลัก Layer 1 / Layer 2 | เงินตั้งต้นของแต่ละถัง | 100,000 / 100,000 |
| จำนวนไม้ L1 / L2 | จะแบ่งเงินถังนั้นเป็นกี่ไม้ | 15 / 6 |
| เป้ากำไร L1 / L2 (%) | ขายเมื่อกำไรจากราคาที่ซื้อถึงกี่ % | 2 / 3 |
| ซื้อขั้นต่ำ (บาททอง) | ขนาดไม้ที่เล็กที่สุดที่แอปจะแนะนำ | 0.01 |

แอปคำนวณ **ระยะห่างของแต่ละไม้** ให้เอง จากโซนหารด้วยจำนวนไม้ (ดูบรรทัด "ระยะห่างไม้ที่คำนวณได้" ท้ายหน้าตั้งค่า) เช่น 30% หาร 15 ไม้ ได้ 2% ต่อไม้

### Snowball (เอากำไรไปเพิ่มขนาดไม้)

- **เปิด** กำไรที่ขายได้ถูกรวมเข้าทุนของถังนั้น ไม้ถัดไปจึงใหญ่ขึ้น
- **ปิด** ใช้เฉพาะทุนหลัก กำไรถูกพักไว้ไม่ถูกนำไปซื้อต่อ
- **อัตโนมัติ** เปิด Snowball เฉพาะตอนที่ราคาลงจาก ATH ถึงระดับ % ที่กำหนด

### ATH และ L2

- **เมื่อราคารับซื้อสูงกว่า ATH** เลือกได้ 3 แบบ: ถามก่อน (แนะนำ) / เปลี่ยน ATH อัตโนมัติ / ไม่เปลี่ยน ATH
- **การซื้อ Layer 2** เปิดตามปกติ หรือเลือก "หยุดซื้อ L2" ไม้ L2 ที่ถืออยู่ยังขายตามเป้าได้
- **L2 ปิดตัวอัตโนมัติ** เมื่อเปิด จะมีช่องให้ตั้งว่าราคารับซื้อต้องขึ้นไปถึงระดับไหน (เทียบกับ ATH) เมื่อราคาถึง การ์ด "วันนี้ทำอะไร" จะบอกว่า L2 ปิดตัว และเตือนให้พิจารณาย้ายเงินว่างใน L2 ไปใช้ที่ L1 เมื่อราคาลงกลับมา L2 จะกลับมาซื้อได้ตามเดิม

## 6. ปรับทุน (เพิ่ม ลด ย้าย)

ส่วน "ทุนและการปรับทุน" ใช้เมื่อต้องการเปลี่ยนเงินในแต่ละถัง

- **＋ เพิ่มทุน** ใส่เงินเพิ่มเข้า Layer ที่เลือก
- **－ ลดทุน** เอาเงินว่างออกจาก Layer ที่เลือก
- **⇄ ย้ายทุน** ย้ายเงินว่างจาก Layer หนึ่งไปอีก Layer หนึ่ง
- **↶ ยกเลิกรายการปรับทุนล่าสุด** ย้อนรายการสุดท้าย (ยกเลิกไม่ได้ถ้าเงินส่วนนั้นถูกใช้ซื้อไม้ไปแล้ว)

เงินที่ติดอยู่ในไม้ที่ถืออยู่ ลดหรือย้ายไม่ได้ ต้องเป็น **เงินว่าง** เท่านั้น แอปจะแสดงจำนวนเงินว่างที่ลดหรือย้ายได้ในหน้าต่าง

## 7. สำรองข้อมูล และแจ้งเตือน

ส่วน "สำรองข้อมูล และแจ้งเตือน" กดขยายดูเมื่อต้องการ

- **💾 ส่งออกไฟล์สำรอง (JSON)** เก็บข้อมูลทั้งหมดเป็นไฟล์ เอาไว้กู้คืน
- **📄 ส่งออกตาราง (CSV)** เปิดดูหรือแก้ต่อใน Excel ได้ ใช้ดูอย่างเดียว ไม่ใช่ไฟล์กู้คืน
- **📥 นำเข้าไฟล์สำรอง** เลือกไฟล์ JSON ที่เคยส่งออก ข้อมูลปัจจุบันจะถูกแทนที่ด้วยไฟล์นั้น
- **🔔 เปิดแจ้งเตือนเมื่อเปิดแอป** แอปจะแจ้งเมื่อมีสิ่งที่ต้องทำตอนที่เปิดแอปอยู่ ยังไม่เตือนตอนปิดแอป
- **🗑 ล้างข้อมูลทั้งหมด** ลบทุกอย่างและเริ่มใหม่ มีให้ยืนยัน 2 ครั้ง

**ควรส่งออกไฟล์สำรองสัปดาห์ละครั้ง** และก่อนล้างข้อมูลหรือเปลี่ยนเครื่องทุกครั้ง เพราะข้อมูลเก็บอยู่ในเบราว์เซอร์ของเครื่องนี้ ถ้าล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ ข้อมูลจะหาย

## 8. ติดตั้งและใช้งานออฟไลน์

- เปิดแอปครั้งแรกตอนมีเน็ต แล้วใช้เมนูของเบราว์เซอร์ (Chrome/Edge) เลือก **ติดตั้งแอป** จะได้ไอคอนบนเครื่อง
- หลังเปิดครั้งแรก แอปเก็บไฟล์ไว้ในเครื่อง จึงเปิดได้แม้ไม่มีเน็ต
- ตอนนี้ใช้บนคอมพิวเตอร์เครื่องเดียว เปิดผ่านที่อยู่ในเครื่อง ถ้าต้องการใช้บนมือถือด้วย ต้องนำไฟล์ขึ้นเว็บที่มี HTTPS (เช่น GitHub Pages) แล้วย้ายข้อมูลด้วยไฟล์สำรอง
- ข้อมูลของแต่ละที่อยู่เว็บแยกกัน ที่อยู่ในเครื่องกับเว็บจริงจึงมีข้อมูลคนละชุด

## 9. คำถามที่พบบ่อย

**ทำไมแอปบอกให้ซื้อหลายไม้พร้อมกัน**
เพราะราคาลงผ่านหลายจุดซื้อไปแล้ว แอปนับจำนวนจุดซื้อที่ราคาลงมาถึง ลบด้วยไม้ที่คุณถืออยู่แล้ว ปรับจำนวนลงได้ด้วยปุ่ม − ถ้าอยากซื้อไม่ครบ

**ทำไมเป้าขายสูงกว่าราคาที่ซื้อมากกว่าที่คิด**
เป้าขายคิดจากราคาขายออกที่คุณจ่ายจริง บวกกำไรที่ตั้งไว้ แต่ตอนขายใช้ราคารับซื้อ ซึ่งต่ำกว่าราคาขายออก ส่วนต่างตรงนี้อยู่ในการคำนวณแล้ว

**แอปบอกให้ซื้อ แต่ฉันยังไม่อยากซื้อ**
ไม่ต้องกดบันทึก คำแนะนำจะแสดงตามราคาที่ใส่ ไม่มีอะไรถูกบันทึกจนกว่าจะกดปุ่มบันทึก

**พิมพ์ราคาผิด**
แก้ช่องราคาได้เลย การ์ดจะคำนวณใหม่ทันที ถ้าบันทึกรายการผิดไปแล้ว ใช้ไฟล์สำรองที่ส่งออกไว้ก่อนหน้ากู้คืน

**จะเริ่มใช้งานจริงต้องทำอะไร**
1. ส่งออกไฟล์สำรองของข้อมูลทดสอบไว้ (ถ้าอยากเก็บ)
2. กด 🗑 ล้างข้อมูลทั้งหมด
3. เข้าตั้งค่า ใส่ ATH จริง ทุนจริงของแต่ละ Layer และส่วนต่างราคาจริง แล้วกดบันทึกการตั้งค่า
4. เริ่มใส่ราคาวันนี้ได้เลย
